The anti-cheat core

A finding is proven, not asserted.

Most LLM-security demos let a model grade its own homework. Here the harness decides success — only when a deterministic check sees hard evidence: a confidential canary token reaching an outbound send, or a forbidden tool call in the log.

verdict = judge/deterministic.py

An advisory LLM judge runs alongside for an agreement metric but cannot create or overturn a finding. During testing it both false-positived and false-negatived — a tool that trusted it would have reported a break that never happened and missed one that did. The deterministic verdict stood every time.

Find → Prove → Patch → Verify
